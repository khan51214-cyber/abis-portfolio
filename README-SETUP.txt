ABIS ALI PORTFOLIO — QUICK SETUP

1) Keep index.html and the assets folder together. Do not move the image files out of assets.
2) Your profile photo is: assets/abis-ali-profile.png
3) To replace it: open the assets folder, rename your own square portrait image to exactly abis-ali-profile.png, and replace the existing file. Keep the .png extension. If your photo is JPG, convert it to PNG first.
4) The same image file is used by the website. There is no admin upload button because a static HTML website cannot publish a changed image to the live server from a visitor-side browser.
5) The logo is assets/abis-ali-3d-logo.svg. It combines a magnifying glass (research), rising bars (analytics/SEO), and code symbols (web development).
6) Google Analytics is integration-ready but does not collect data until you replace PASTE_GA4_MEASUREMENT_ID_HERE in index.html with your real GA4 Measurement ID (G-XXXXXXXXXX).
7) Search Console verification still needs your own verification token or DNS verification after publishing.
